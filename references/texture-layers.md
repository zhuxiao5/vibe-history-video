# 纹理层：按对象归属设计

纹理用于说明材质、环境或动作，不是结构和叙事的替代品。先确认它属于哪个对象或图层，再决定形状、密度、尺寸、对比、寿命和时间行为。默认克制；不把星屑式亮点铺满全屏。

## 可选材质

| 材质 | 可能归属 | 设计与检查重点 |
|---|---|---|
| 地形暗纹 | 山地、平原或底图 | 顺应地貌和光照层次；局部放大确认不干扰边界、河道和文字 |
| 海面横纹 | 水面 | 顺水面方向组织，和海岸、路径区分；检查相邻帧稳定性 |
| 泥沙颗粒 | 泥沙、水流或沉积过程 | 让颗粒随对象或流向变化，避免在无关区域同步闪烁 |
| 微光颗粒 | 特定暗背景或光域 | 仅在参考与画面需要时局部使用；控制对比、尺寸、密度和闪烁 |
| 纸面杂质 | 纸张或浅色地图底 | 固定或缓慢变化均可，需保留文字和地图线条的可读性 |
| 手绘笔触与飞白 | 路径、轮廓或插画线稿 | 笔触与飞白围绕被绘制线条分布；不等同于全屏撒点 |

表中是可选设计方向，不是要求每个项目同时启用的层。某种纹理只有在具体参考和成片中得到验证后，才能作为该项目的选择。

## xilo 参考的边界

旧版 `xilo` 测量描述的是一段白底手绘线稿：中灰粗笔触周围有更浅的墨点，碎屑贴近线条。它不属于本系列参考范围，也不能升格为全系列默认。若项目确实要迁移这种材质，可将其作为可选笔触方案，沿路径生成连续笔画与局部飞白，再按目标画面重新校准。旧记录中的具体尺寸、灰度和数量只属于该样本，不直接沿用到新作品。

## 颗粒检查

不要假定亮区绝无颗粒，也不要把某次暗部颗粒统计写成全局衰减曲线。视频压缩、发光、颜色阈值和对象运动都会影响像素统计。检查时：

1. 先在静帧上确认颗粒归属和空间分布，再检查连续帧中的寿命与闪烁。
2. 对对象附近做局部裁切，比较纹理开启与关闭时，轮廓、动作和文字是否更清楚。
3. 检查最终编码画面，确认颗粒没有盖过解释对象，也没有造成无意义的全屏高频变化。
4. 记录观察到的窗口和方法；没有直接证据时保留为设计假设。

纹理代码接口由项目运行时提供。这里仅说明材质归属、设计边界与视觉验证原则，不预设函数名称、参数或调用顺序。
