# 写实背景图：从分镜设计到生成落盘

> 适用：**需要写实底图**的片子（历史场景、器物、环境）。
> 来源：2026-10-15《大泽乡》一期实战，10 张图全流程跑通。
>
> ⚠️ **本文件只管「背景图」。** 纯代码纹理走 [纹理层](texture-layers.md)，两者不冲突。

---

## 〇、为什么要把背景图提到分镜阶段

《大泽乡》之前只用 **2 张**底图在 6 场里反复用 —— 观感上"不够充实"。
正解：**背景图不是"后期配图"，是"分镜的一部分"。**

分镜阶段就要定：**几张、每张干嘛、文字叠哪。**

### 数量基准

**一个 120 秒的视频 → 10 张**（约每 12 秒换一张，与换句错开）。

| 场数 | 分配 |
|---|---|
| 6 场 | 长场（>20s）2 张，短场（<15s）1 张 |

### ⭐ 四种功能必须配齐（最容易犯的错）

**10 张如果都是"氛围图"，就变成幻灯片。** 每张必须认领一个功能：

| 功能 | 作用 | 画面特征 | 张数 |
|---|---|---|---|
| **① 建立** | 交代时空，让观众"落地" | 大景、有地标物 | 2 |
| **② 聚焦** | 把物件/人物推到眼前 | 特写、浅景深 | 4 |
| **③ 对比** | 两张图形成前后/左右对照 | 构图对称、色调一冷一暖 | 2 |
| **④ 转折/收尾** | 情绪落点 | 空景、留白多 | 2 |

### 硬约束（写分镜要求时就必须满足）

| 约束 | 数值 | 原因 |
|---|---|---|
| **文字净区** | 每张 ≥35% 面积的暗区/净区 | 主字幕在 **y866–944** |
| **主体避开字幕带** | 人物/器物主体不进 y866–944 | 否则压字幕 |
| **亮度目标** | 处理后在 **14–26** 区间 | 与系列一致 |
| **相邻两张要有差异** | 构图/色调至少变一样 | 否则像重复 |

## 一、两步走

```
第①步  分镜里写「简写要求」        ← 格式：图N ｜ 场 ｜ 功能 ｜ 画面一句话 ｜ 亮度色调 ｜ 有无主体
   ↓   交用户确认
第②步  出「详细要求」（可执行）      ← 画面/构图/光/色调/留白/禁止项 + 一句话给找图的人
   ↓
第③步  生成或找图 → 标定 → 落盘
```

**⚠️ 不要跳过第①步直接做第②步** —— 分配和功能没定，详细要求就是白写。

---

## 二、图片来源（三种，都支持）

| 方案 | 说明 |
|---|---|
| **A. 用户提供** | 最可靠。给出「详细要求」当作业单 |
| **B. AI 生成** | 见下文第三节（`gen-bg.py`） |
| **C. 混合** | 关键画面用户给，过渡画面生成 |

**给用户找图时，优先提示这一条**：
> 找**「上半暗、下半有光」**的图。因为字幕在底部，
> 上暗好叠字，下半的渐变带正好放字幕。**这个构图最省事。**

## 三、AI 生成（`gen-bg.py`）

```sh
# 端点/key 三种给法（按优先级）
export IMG_KEY=sk-xxx              # ① 环境变量
# 或在项目根建 local-endpoint.json  {"api":"...","key":"..."}   ← ② 推荐，记得 .gitignore

python <skill>/scripts/gen-bg.py --prompts tools/prompts.json --keys fig01 fig05
python <skill>/scripts/gen-bg.py --prompts tools/prompts.json            # 全部
```

### ⚠️ 三个实测坑（都踩过，别再踩）

**坑 1｜端点必须是 `/v1/images/generations`**
用 `/v1/chat/completions` 会返回：
`model xxx is only supported on /v1/images/generations and /v1/images/edits`

**坑 2｜`size` 参数被完全忽略**
传 `1536x1024` / `1792x1024` / `1024x1024` **都返回 1254×1254 方图**。
→ **解法：在 prompt 里明确写「16:9 横版」** → 返回 **1672×941** ✅

**坑 3｜否定句会被误读**
写「不要有城楼」→ **它真给你加城楼**。
→ 改成**正向描述**：「地平线上没有任何建筑」/「背景只有一片模糊的暗色荒野，空无一物」

### 返回体与耗时

- `data[0].b64_json`（base64 PNG）+ `data[0].generation_id`
- 单张 **35–54 秒**

## 四、Prompt 结构：「固定框架 + 变量槽」

**不要 10 张各写一遍完整 prompt。** 拆成两部分：

### 固定框架（10 张共用）

```
制作一张「暗调电影感历史写实插画」，作为历史科普视频的无字背景。画面为 16:9 横版。

视觉风格：
历史电影概念美术，写实人物与场景，细腻的材质表现，少量绘画质感。
画面沉稳、厚重、克制，有真实的历史生活气息。

色彩与光线：
近黑、深褐、冷灰为主，低饱和。局部以火把或烛光提供琥珀色暖光，
与冷暗环境形成对比。大面积暗部保留细节，人物和器物轮廓清晰。
避免整张画面泛黄或过度明亮。

空间与材质：
前景、中景、远景层次明确，具有电影景深。
根据场景加入适量雨雾、烟尘或湿地反光。
认真表现粗麻织物、旧木、竹片、泥土等符合时代的材料。

构图：
16:9 横版，宽幅构图。主要人物和器物位于画面下半部，
画面中央及中上部是大面积自然、低细节的暗色空间，便于后续叠加字幕。
暗区要与环境自然融合，不要出现突兀的纯黑色块。
视觉重心在画面下三分之一。人物以背影或侧影为主。

时代考据：
【时代】。服装为……，无马镫，无铁质农具，无砖石长城。器物为旧木、竹、粗陶、青铜。

约束：
画面中只有环境与人物，没有任何文字、标题、字幕、标识、水印、地图、旗帜。
背景是空旷自然的荒野，没有多余的建筑。
```

**只有 `【时代】` 和最后一行是变量。**

### 变量槽（每张填 4 项）

```
【时代】     秦代 / 唐代 / 西汉 / 战国 …
【画面内容】 人物 + 事件 + 场景 + 正在做什么（一句话）
【核心器物】 画面必须出现的关键物件
【特殊留白】 除默认（中上部）外，额外要空出的区域  ← 见下
```

**「特殊留白」是最容易被忽略、也最要命的一项**：
- 某场右侧要叠对照文字 → 图必须**右侧留净区**
- 某场上方要放计数 → 图必须**上方留暗**
- 如果图的净区不对，那一段的信息**就没地方放**

### 可选的加强槽（题材需要时加）

```
【比例与透视】  低机位 / 平视 / 微俯；不要广角畸变
【人物数量】    1–3 人（避免群像，AI 容易崩）
【人物朝向】    背影 / 侧影为主（避免正脸）
【画面颗粒】    轻微胶片颗粒，不要数码锐利感
【时代细节反例】不用铁质农具、不用砖石长城、不用马镫   ← 比"符合时代"更硬
【不出现的物件】逐个列
```

**「时代细节反例」比「符合某代」有效得多** —— 后者太空，前者是硬禁令。

## 五、⭐ 亮度必须「逐张标定」（`calibrate-bg.py`）

```sh
python <skill>/scripts/calibrate-bg.py --srcdir assets/bg/gen --outdir assets/bg
```

### 为什么不能一刀切 —— 有实测数据

《大泽乡》10 张图标定出来的系数：

| 图 | 01 | 02 | 03 | 04 | 05 | 06 | 07 | 08 | 09 | 10 |
|---|---|---|---|---|---|---|---|---|---|---|
| **系数** | 0.80 | **0.47** | 0.55 | 0.71 | 0.80 | **0.50** | 0.80 | **0.50** | **0.41** | 0.80 |

**跨度 0.41–0.80，差近一倍。**

→ 一刀切用 0.6：一半图偏亮、一半被压过头。
→ **「逐张标定」不是理论，是这张表算出来的。**

### 标定逻辑

从 `0.80` 起按 `0.03` 逐档下探，取**第一个同时满足**的：
- 字幕带（y866–944）均值 **≤55**
- 字幕带亮像素（>150）占比 **≤1%**
- 上半幅（y0–820）落在 **14–26**

都不满足时退而求其次：**只保字幕带**（下限 0.40）。

### 处理链（顺序不可换）

```
① 缩放 1920×1080
② 压亮度      ← 系数逐张标定
③ 提暗部（避免死黑）
④ 减饱和
⑤ 暖褐色调（对齐系列）
⑥ 轻微模糊（降高频细节，贴近矢量感）
```

## 六、接进画面（`scene.js`）

```js
// 底图加载：必须等 decode() 完成，否则首帧是空的
function loadImage(src){
  return new Promise((res)=>{
    const im=new Image();
    im.onload=()=>{ (im.decode?im.decode():Promise.resolve()).then(()=>res(im)).catch(()=>res(im)); };
    im.onerror=()=>{ console.warn('底图加载失败:',src); res(null); };
    im.src=src;
  });
}

// 铺满 + 暗化层 + 底部渐变带（给字幕留更暗的底）
function bg(g,im,{dim=0.45,zoom=1,focus=[0.5,0.5],band=0.62,bandA=0.82}={}){
  if(!im)return;
  const s=Math.max(width/im.width,height/im.height)*zoom;
  const w=im.width*s,h=im.height*s;
  g.drawImage(im,(width-w)*focus[0],(height-h)*focus[1],w,h);
  g.fillStyle=`rgba(10,9,7,${dim})`;g.fillRect(0,0,width,height);
  if(band>0){
    const grd=g.createLinearGradient(0,height*band,0,height);
    grd.addColorStop(0,'rgba(10,9,7,0)');
    grd.addColorStop(1,`rgba(10,9,7,${bandA})`);
    g.fillStyle=grd;g.fillRect(0,height*band,width,height*(1-band));
  }
}
```

**每场按节拍切图**（不要一场一图用到底）：
```js
const img = local < 9 ? BGS.fig01 : BGS.fig02;   // 前 9 秒 / 后 9 秒
bg(g, img, {dim:0.45, zoom:1+local*0.002, focus:[0.5,0.5]});
```
`zoom` 随时间缓推 → 静图也有"呼吸感"。

## 七、验收（必跑）

| 检查 | 脚本 | 判据 |
|---|---|---|
| 图本身亮度 | `calibrate-bg.py` | 字幕带亮像素 ≤1% |
| **图形压文字** | **坐标手算**（脚本测不出） | 主体不进 y866–944 |
| **文字重叠** | `check-overlap-live.py` | 逐帧 0 重叠 |
| 像素排版 | `check-layout.py` | 0 问题 |
| 时序 | `check-timing.py` | 0 越界 |

**⚠️ `check-layout.py` 是像素法，测不出「图形压文字」**（灰/暗元素不过阈值）。
图形占位必须**逐场列 y 范围手算**。

## 八、一句话总结

> **背景图在分镜阶段就要设计：几张、每张干嘛、文字叠哪。**
> **10 张要有 4 种不同功能。**
> **生成时 prompt 必须写「16:9 横版」，否定句要改成正向描述。**
> **处理时亮度系数逐张标定（实测跨度可达一倍）。**
