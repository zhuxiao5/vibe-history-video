# V02动效技术示例

24秒、1920×1080、30fps、静音。不是历史制度成片，也不是原片复刻。地形、建筑、火焰和100/200等阈值为示意，不作考据。

0–8秒：持续字波、同行重点字号与模糊缩回、固定基线描线。
8–15秒：读数跨阈值时点亮节点，世界层多轴轻震与小幅zoom，文字只参与16%幅度。
15–24秒：点列路线、移动亮头/尾迹、按真实路径进度点亮节点、到站扩散虚线环。

预览里的勾选框能切换新通道，用同一时刻比较基础文字/路径与增加动效后的结果；慢相机、基本文字入退场和火焰本身仍保留。MP4导出默认为动效启用。

`shots.json`是文字、计数、重音、信号时刻的真源。`scene.js`负责示意主体；修改本片应同步重写文案与对象，不能只换标题作为新片。
