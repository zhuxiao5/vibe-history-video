# 受箭到回正：24 秒焦点示例

通过 `node <skill>/scripts/create-project.mjs --template focus --out <新目录>` 创建。静音、不含用户音乐；生成项目包含共用 motion/history-kit 与浏览器预览。可以直接渲染 30fps MP4。

本例展示：先建立完整主体，再推近落箭舷侧；旧句退出、新句横向归位；掉头时俯视成为主景；第二轮落箭逐步改变倾斜，最终回到剖面。风险/结果句采用更短的解析和轻微缩放，叙述句保持较慢的归位。文字在屏幕层，船体在世界层。

shots.json 是实际文字和镜头参数；cues.json 经配套 frame-sync-sfx 的 timeline.py 生成 events.js（只用 Python 标准库即可）。无声场景依然可以消费同一份事件时间。修改 cue 后必须重新编译，不手改 events.js。

图元、回正幅度、落箭数量和视图切换都是说明机制的设计，不是古代船型、受力公式或射箭实录。claims.json 沿用本地草船借箭工程的事实记录，不代表对其来源做了新的独立核查。新题材应重新核史料与建模，不能只改标题。
